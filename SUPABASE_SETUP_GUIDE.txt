================================================================================
PARIDHAN - COMPLETE SUPABASE SETUP & CONFIGURATION GUIDE
Hyperlocal Fashion Marketplace with Direct Bargaining & Real-time Delivery Dispatch
================================================================================

This document explains how to set up the entire database in Supabase in 1 step,
configure storage buckets, connect API keys, and access the pre-loaded dummy data
for every role.

================================================================================
1. 1-STEP DATABASE SETUP (SINGLE CONSOLIDATED SCRIPT)
================================================================================

All schema migrations, PostGIS radius functions, bargain-to-cart sync triggers,
RLS security policies, and comprehensive dummy test data are in a single file:

📁 Path: `supabase/complete_setup.sql`

Steps:
1. Create a free project on Supabase (https://supabase.com).
   - Region: South Asia / Mumbai (ap-south-1) for lowest latency in India.
2. In your Supabase Dashboard, click on "SQL Editor" in the left navigation bar.
3. Click "New Query".
4. Open `supabase/complete_setup.sql` from this repository, copy its ENTIRE contents,
   paste it into the SQL Editor, and click "RUN" (Green button).
5. You will see "PARIDHAN SETUP COMPLETE! All tables, PostGIS RPCs, triggers, and
   comprehensive multi-role seed accounts are ready."

================================================================================
2. CONNECT YOUR SUPABASE KEYS
================================================================================

1. Go to "Project Settings" -> "API" in your Supabase Dashboard.
2. Copy your:
   - Project URL (e.g. `https://your-project-id.supabase.co`)
   - anon / public API key (e.g. `sb_publishable_...` or JWT token)
3. Paste them into `apps/mobile/lib/core/constants/app_constants.dart`:

```dart
class AppConstants {
  static const String defaultSupabaseUrl = 'https://YOUR_PROJECT_ID.supabase.co';
  static const String defaultSupabaseAnonKey = 'YOUR_ANON_PUBLIC_KEY';
}
```

(Optional: Set `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in `backend/.env`
if running the AI FastAPI server).
