1. QUICK STEP-BY-STEP SETUP INSTRUCTIONS
================================================================================

Step 1: Create a Supabase Project
---------------------------------
1. Go to https://supabase.com and create a new project (e.g., "paridhan-prod").
2. Choose your region (e.g., South Asia / Mumbai - ap-south-1 for lowest latency in India).
3. Set a secure database password and wait ~2 minutes for project provisioning.

Step 2: Run the SQL Schema Script
---------------------------------
1. In the Supabase Dashboard, click on "SQL Editor" in the left sidebar.
2. Click "New Query".
3. Copy the entire contents of SECTION 3 below and paste it into the editor.
4. Click "Run" (Green button). Verify "Success. No rows returned".

Step 3: Run the Seed Data Script
--------------------------------
1. In the SQL Editor, create another new query.
2. Copy the entire contents of SECTION 4 below and paste it.
3. Click "Run" to populate Categories, Handloom Brands, and Jaipur Heritage Boutiques.

Step 4: Create Storage Buckets
------------------------------
1. In the left sidebar, click "Storage".
2. Create the 4 public/private buckets as specified in SECTION 2.

Step 5: Get Project Keys for Flutter App
---------------------------------------
1. In the left sidebar, go to "Project Settings" -> "API".
2. Copy "Project URL" (e.g., https://xyz.supabase.co).
3. Copy "anon public" API Key.
4. Put these values in `apps/mobile/.env`.

================================================================================
2. SUPABASE STORAGE BUCKETS SETUP
================================================================================

Create the following 4 Storage Buckets under "Storage" in Supabase:

1. `product-images`
   - Public: YES
   - File size limit: 5 MB
   - Allowed MIME types: image/jpeg, image/png, image/webp

2. `shop-banners`
   - Public: YES
   - File size limit: 5 MB
   - Allowed MIME types: image/jpeg, image/png, image/webp

3. `kyc-documents`
   - Public: NO (Private - accessible only by seller owner and admin)
   - File size limit: 10 MB
   - Allowed MIME types: image/jpeg, image/png, application/pdf

4. `return-images`
   - Public: YES
   - File size limit: 5 MB
   - Allowed MIME types: image/jpeg, image/png, image/webp

-- Timestamp Auto-Updater Function
create or replace function update_updated_at_column()
returns trigger as $$
begin
  new.updated_at = now();
  return new;
end;
$$ language plpgsql;

-- Check if current authenticated user is an Admin
create or replace function public.is_admin()
returns boolean as $$
begin
  return exists (
    select 1 from public.profiles
    where id = auth.uid() and role = 'admin'
  );
end;
$$ language plpgsql security definer;

-- PostGIS Geospatial RPC: Get Nearby Boutiques within Radius (Kilometers)
create or replace function public.get_nearby_shops(
  lat double precision,
  lng double precision,
  radius_km double precision default 10.0
)
returns table (
  id uuid,
  seller_id uuid,
  name text,
  description text,
  address text,
  banner_url text,
  is_verified boolean,
  avg_rating numeric,
  distance_meters double precision
) as $$
begin
  return query
  select
    s.id,
    s.seller_id,
    s.name,
    s.description,
    s.address,
    s.banner_url,
    s.is_verified,
    s.avg_rating,
    st_distance(s.location, st_setsrid(st_makepoint(lng, lat), 4326)::geography) as distance_meters
  from public.shops s
  where s.status = 'verified'
    and s.location is not null
    and st_dwithin(s.location, st_setsrid(st_makepoint(lng, lat), 4326)::geography, radius_km * 1000)
  order by distance_meters asc;
end;
$$ language plpgsql stable;

-- Deduct Variant Stock on Successful Order/Payment
create or replace function public.deduct_variant_stock(
  p_variant_id uuid,
  p_qty integer
)
returns void as $$
begin
  update public.product_variants
  set stock_qty = greatest(0, stock_qty - p_qty),
      updated_at = now()
  where id = p_variant_id;
end;
$$ language plpgsql security definer;

-- Trigger: Automatically Create public.profiles record when new user signs up in auth.users
create or replace function public.handle_new_user()
returns trigger as $$
begin
  insert into public.profiles (id, email, full_name, role, accepted_terms_at)
  values (
    new.id,
    new.email,
    coalesce(new.raw_user_meta_data->>'full_name', 'User'),
    coalesce((new.raw_user_meta_data->>'role')::user_role, 'consumer'),
    case when (new.raw_user_meta_data->>'accepted_terms')::boolean = true then now() else null end
  );
  return new;
end;
$$ language plpgsql security definer;

drop trigger if exists on_auth_user_created on auth.users;
create trigger on_auth_user_created
  after insert on auth.users
  for each row execute function public.handle_new_user();

-- Trigger: Enforce Minimum Bargaining Floor Price
create or replace function public.enforce_bargain_floor_price()
returns trigger as $$
declare
  v_min_price numeric;
begin
  select min_bargain_price into v_min_price
  from public.products
  where id = new.product_id;

  if new.consumer_offer < v_min_price then
    raise exception 'Offer amount % is below the minimum acceptable bargain price % for this product',
      new.consumer_offer, v_min_price;
  end if;

  return new;
end;
$$ language plpgsql;

drop trigger if exists check_bargain_offer_floor on public.bargains;
create trigger check_bargain_offer_floor
  before insert or update of consumer_offer on public.bargains
  for each row execute function public.enforce_bargain_floor_price();

-- Trigger: Auto-Add to Cart on Bargain Accepted
create or replace function public.on_bargain_accepted_auto_cart()
returns trigger as $$
begin
  if new.status = 'accepted' and (old.status is distinct from 'accepted') and new.agreed_price is not null then
    insert into public.cart_items (
      consumer_id,
      product_id,
      variant_id,
      quantity,
      bargain_id,
      agreed_price,
      reserved_until
    )
    values (
      new.consumer_id,
      new.product_id,
      new.variant_id,
      1,
      new.id,
      new.agreed_price,
      now() + interval '24 hours'
    )
    on conflict (consumer_id, variant_id) do update set
      agreed_price = excluded.agreed_price,
      bargain_id = excluded.bargain_id,
      reserved_until = excluded.reserved_until;
  end if;
  return new;
end;
$$ language plpgsql security definer;

drop trigger if exists auto_cart_on_bargain_accepted on public.bargains;
create trigger auto_cart_on_bargain_accepted
  after update of status on public.bargains
  for each row execute function public.on_bargain_accepted_auto_cart();

-- User Profile Policies
create policy "Profiles readable by owner or admin" on public.profiles for select using (auth.uid() = id or is_admin());
create policy "Users can update their own profile" on public.profiles for update using (auth.uid() = id);

-- Seller Shop & Product Management Policies
create policy "Sellers can manage their own shop" on public.shops for all using (seller_id = auth.uid());
create policy "Sellers can manage their own products" on public.products for all using (exists (select 1 from public.shops where shops.id = products.shop_id and shops.seller_id = auth.uid()));
create policy "Sellers can manage their own variants" on public.product_variants for all using (exists (select 1 from public.products join public.shops on shops.id = products.shop_id where products.id = product_variants.product_id and shops.seller_id = auth.uid()));

-- Bargain Real-Time Policies
create policy "Participants can view bargain" on public.bargains for select using (consumer_id = auth.uid() or seller_id = auth.uid() or is_admin());
create policy "Consumers can initiate bargains" on public.bargains for insert with check (consumer_id = auth.uid());
create policy "Participants can update bargains" on public.bargains for update using (consumer_id = auth.uid() or seller_id = auth.uid());
create policy "Participants can view messages" on public.bargain_messages for select using (exists (select 1 from public.bargains where bargains.id = bargain_messages.bargain_id and (bargains.consumer_id = auth.uid() or bargains.seller_id = auth.uid())));
create policy "Participants can insert messages" on public.bargain_messages for insert with check (sender_id = auth.uid() and exists (select 1 from public.bargains where bargains.id = bargain_messages.bargain_id and (bargains.consumer_id = auth.uid() or bargains.seller_id = auth.uid())));

-- Cart & Address Policies

create policy "Users can manage their addresses" on public.delivery_addresses for all using (user_id = auth.uid());

-- Orders Policies
create policy "Consumers can view their orders" on public.orders for select using (consumer_id = auth.uid() or exists (select 1 from public.shops where shops.id = orders.shop_id and shops.seller_id = auth.uid()) or is_admin());
create policy "Consumers can create orders" on public.orders for insert with check (consumer_id = auth.uid());
create policy "Sellers and Admins can update orders" on public.orders for update using (exists (select 1 from public.shops where shops.id = orders.shop_id and shops.seller_id = auth.uid()) or is_admin());
create policy "Order items readable by order participants" on public.order_items for select using (exists (select 1 from public.orders where orders.id = order_items.order_id and (orders.consumer_id = auth.uid() or exists (select 1 from public.shops where shops.id = orders.shop_id and shops.seller_id = auth.uid()) or is_admin())));

-- Notifications Policies
create policy "Users can view their notifications" on public.notifications for select using (user_id = auth.uid());

5. SUPABASE EDGE FUNCTIONS DEPLOYMENT GUIDE
================================================================================

Paridhan utilizes 3 Deno Edge Functions located in `supabase/functions/`:

1. `create-razorpay-order`
   - Purpose: Calculates 90% boutique payout & 10% platform commission, creates Razorpay Route split order.
   - Command: `supabase functions deploy create-razorpay-order`

2. `razorpay-webhook`
   - Purpose: Validates HMAC SHA256 signature, marks order paid, decrements inventory stock.
   - Command: `supabase functions deploy razorpay-webhook`

3. `expire-stale-bargains`
   - Purpose: Scheduled cron to mark bargains past 24h as expired.
   - Command: `supabase functions deploy expire-stale-bargains`

Required Secrets in Supabase (Set in Project Settings -> Edge Functions -> Secrets):
- `RAZORPAY_KEY_ID`: Your Razorpay Key ID (e.g., rzp_test_...)
- `RAZORPAY_KEY_SECRET`: Your Razorpay Secret
- `RAZORPAY_WEBHOOK_SECRET`: Secret from Razorpay Dashboard Webhook settings
- `SUPABASE_SERVICE_ROLE_KEY`: Secret service key for backend DB operations
